# Food Control Android

Нативное Android-приложение для контроля ежедневного рациона и склада продуктов.

## Что уже реализовано

- Экран `Рацион` с приёмами пищи: `Утренник`, `Завтрак`, `Обед`, `Ужин`.
- Индивидуальная кнопка `Съел` у каждого продукта.
- Общая кнопка `Съел приём` у всего приёма пищи.
- Если продукт уже списан, повторное нажатие отменяет списание и возвращает продукт на склад.
- Если продукта не хватает, вместо кнопки показывается `!`.
- Горизонтальный список закрытия нутриентов над рационом.
- Инфо-режим `i`: текст нутриентов листается внутри неподвижной панели.
- Режим редактирования рациона.
- Добавление продукта в рацион из горизонтального списка продуктов склада.
- Перетаскивание продуктов рациона: долгое нажатие на строку и перенос в нужное место. Работает и между приёмами пищи.
- Экран `Склад` ниже рациона.
- Добавление количества на склад.
- Вычитание количества со склада через минусовое значение, например `-200 гр`, `-2 шт`, `-1 уп`.
- Учёт партий и ближайшего срока годности.
- Уведомления Android о сроке годности и о том, что рациона хватает на 2 дня или меньше.
- Ежедневная проверка уведомлений через `AlarmManager`.
- Сброс съеденных тумблеров по московскому дню.
- Анимации нажатий, появления/изменения панелей.
- Данные хранятся локально в `SharedPreferences`.

## Как получить APK через Android Studio

1. Установи Android Studio.
2. Распакуй архив проекта.
3. Открой папку `FoodControlAndroid` через `File > Open`.
4. Дождись Gradle Sync.
5. Если Android Studio попросит установить Android SDK Platform 35 или Build Tools — соглашайся.
6. Нажми `Build > Build Bundle(s) / APK(s) > Build APK(s)`.
7. APK появится здесь:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## Как получить APK через GitHub Actions

1. Создай пустой GitHub-репозиторий.
2. Загрузи туда содержимое папки `FoodControlAndroid`.
3. Открой вкладку `Actions`.
4. Запусти workflow `Build APK`.
5. Скачай artifact `food-control-debug-apk`.

## Важное про push-уведомления

В приложении реализованы локальные Android-уведомления: они создаются самим приложением по расписанию и подходят для твоего сценария — срок годности, нехватка продуктов, проверка склада.

Удалённые push-уведомления с сервера через Firebase Cloud Messaging здесь не подключены, потому что для них нужен отдельный Firebase-проект, `google-services.json` и сервер/отправитель сообщений. Для текущей задачи это не требуется.

## Технические параметры

- Язык: Java.
- UI: нативный Android Views, без WebView и без HTML.
- Минимальная версия: Android 8.0, API 26.
- Target SDK: Android 15, API 35.
- Внешних библиотек нет.
